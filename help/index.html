User manual

Write, plan and sketch in one small Mac app.

TinyEd is a small text editor for macOS with a dual editor, an AI assistant, image markup, Kanban boards and whiteboards. This manual shows you how everything works.

Getting started

TinyEd is a small, fast editor for macOS. It opens plain text, Markdown and source code. You can also annotate screenshots, plan tasks on Kanban boards and sketch on whiteboards – all in one window.

Install TinyEd

  1. Download the latest TinyEd.dmg from the TinyEd releases page.
  2. Open the disk image and drag TinyEd into your Applications folder.
  3. Start TinyEd. The app is signed and notarized by Apple, so it opens without a warning.

Updates

TinyEd checks for new versions once a day. To check right away, choose TinyEd › Check for Updates…. The update dialog shows what is new before you install.

What you need

  • A Mac with macOS 14 Sonoma or later.
  • Optional: iCloud Drive. TinyEd stores new files in the TinyEd folder in iCloud Drive. Without iCloud Drive it uses your Documents folder.
  • Optional: your own OpenRouter API key for the AI assistant.
Good to know: Everything except the AI assistant works offline and without an account.

The main window

The window has four areas. Every command applies to the active document.

  1. Sidebar – all commands in sections you can fold: New, File, Files, Projects, Kanban, Whiteboards, Edit, View, AI Assistant, Image and Themes. Show or hide it with ⌃⌘S.
  2. Header – the tabs Documents, Kanban and Whiteboard, the connector between document and board, and the file name with its save lamp.
  3. Editor – where you write, annotate, plan or draw.
  4. Status bar – line and column, word and character count, and the Dual editor switch.

The save lamp

The dot before the file name shows the state of your document: green means Saved, orange means Unsaved changes.

The New button

The New button at the top of the sidebar creates or opens a document, project, board or whiteboard.

The file browser

The Files section shows a folder tree with all files TinyEd can open. Click a file to open it in the active editor. Choose Folder sets the root folder, and TinyEd remembers it. Refresh reloads the tree.

When you switch to another file, TinyEd saves a named file silently. For an untitled draft it asks first.

Writing and editing text

TinyEd opens plain text, Markdown, configuration files and source code – for example .txt, .md, .json, .yaml, .toml, .ini, .env, .sh, .swift, .py, .go, .rs and .sql. Rich text (RTF) is not supported.

Open and save

  • New ⌘N starts an empty document.
  • Open… ⌘O opens a file. You can also drag files from the Finder into the window.
  • Save ⌘S and Save As… ⇧⌘S save the active document.
  • File › Recent Files lists your last ten files. Open the first nine with ⌘1 to ⌘9. Clear Menu empties the list.

A new document is called Untitled. If you close a document with unsaved changes, TinyEd asks: Save, Don’t Save or Cancel.

Undo and redo

Use ⌘Z to undo and ⇧⌘Z to redo, or the buttons in the Edit section. A change made by the AI assistant is one single undo step.

Word wrap

Turn on Word wrap in the View section or under View › Word Wrap to wrap long lines. Turn it off to scroll horizontally instead – handy for code and logs.

Markdown preview

For Markdown files, a switch in the header toggles between Source (editable) and Formatted (read-only). The shortcut is ⇧⌘P. To type again, switch back to the source view.

Counts in the status bar

The status bar shows the cursor position (Line 12, Column 4), the number of words and characters, and how many characters you have selected.

Find and replace

Press ⌥⌘F or choose Edit › Find and Replace…. The Find & Replace panel opens above the editor.

  1. Type your search into Find…. The counter shows the current match and the total, for example 1/5.
  2. Jump with Find Next (↩) and Find Previous.
  3. Type the new text into Replace with…. Then click Replace for the current match or Replace All for every match.
  4. Close the panel with Close or Esc.

Two options refine the search: Case Sensitive and Regular Expression. The classic macOS find bar is still there, too: ⌘F, ⌘G and ⇧⌘G.

Tips for regular expressions:
  • \s+$ finds spaces at the end of lines – replace them with nothing.
  • ^\s+ finds indentation at the start of lines.
  • \bTODO\b finds the word TODO, but not TODOS.

Dual editor

Work on two files side by side. Turn on the Dual editor switch at the bottom right of the status bar. A second, empty editor opens on the right.

  • Each editor holds text or an image: text and a screenshot, two text files, or two images.
  • The active editor has a yellow frame. All sidebar and menu commands apply to it.
  • Click into an editor to make it active, or press ⇧⇥ to switch.
  • Each editor has its own header with save lamp and file name (Untitled 1, Untitled 2). The status bar shows the active one.

Back to one editor

Turn the switch off. The active editor stays, the other one closes – TinyEd asks you to save if needed. An empty editor never replaces one with content, so you cannot lose text by accident.

Good to know: Font and color profile apply to both editors.

AI assistant

The AI assistant improves, corrects, translates or summarizes your text. It works on the selected text. If nothing is selected, it works on the whole document.

Set it up once

  1. Create an API key at openrouter.ai/keys.
  2. Open TinyEd › Settings… (⌘,) and go to AI Assistant.
  3. Paste the key (it starts with sk-or-v1-) and click Save. TinyEd checks the key right away and stores it in your keychain.
  4. Optional: pick another Default Model.

The eight functions

  • Improve Text – clearer style, same language.
  • Grammar & Spelling – fixes mistakes, nothing else.
  • Translate (EN/DE) – detects the language and translates English to German or German to English.
  • Summarize – a short summary.
  • Expand Text – adds details and full sentences.
  • Make Formal – a professional, business tone.
  • Make Casual – a relaxed, friendly tone.
  • Optimize Prompt – rewrites a prompt for an AI so it gets better answers.

Use it

  1. Select text, or select nothing to use the whole document.
  2. Pick a function in the AI Assistant section of the sidebar or in the AI menu of the header. ⇧⌘A opens the assistant directly.
  3. Click Process. Compare Original and AI Result side by side.
  4. Not happy? Click Regenerate for another version.
  5. Click Apply. The result replaces your text – ⌘Z brings the original back.
Good to know: Links, email addresses and file paths stay exactly as they are – TinyEd checks the result and restores them if needed. Your text goes to OpenRouter only when you click Process. OpenRouter bills the usage to your account.

Annotating images

Open a PNG or JPEG like any other file: with ⌘O, from the Files section or by dragging it into the window. The image opens in the editor, and the Image section of the sidebar holds the tools.

  • Select – click a mark to move or delete it.
  • Arrow, Rectangle and Circle – drag to draw.
  • Freehand – draw freely with the mouse or trackpad.
  • Text – click and type a comment.

Set Color, Line width and Text size before you draw. ⌘Z undoes the last mark. Large images fit into the window automatically; pinch on the trackpad to zoom.

Save

  • ⌘S writes the marks into the original image. TinyEd asks once: Overwrite original? – the original cannot be restored afterwards. Choose Save a copy… if you want to keep it.
  • ⇧⌘S saves a copy as PNG or JPEG.
  • TinyEd saves in the full pixel size of the original.
Tips for bug reports: Turn on the dual editor and open your notes on the left and the screenshot on the right. Mark the problem with a red rectangle and add a short text comment.

Kanban boards

Plan tasks on a board with five fixed columns: Backlog, Design, Engineering, Testing and Done. A board is a .kan file. TinyEd stores new boards in iCloud Drive › TinyEd › Kanban and lists them in the Kanban section of the sidebar.

Create and open a board

  • Choose File › New Kanban Board (⇧⌘N) or use the New button.
  • Click a board in the Kanban section to open it. It appears in the Kanban tab of the header – this tab only shows while a board is open.
  • Close the board with the ✕ on its tab.

Work with cards

  • Click Add card at the bottom of a column.
  • A card has a Title, Notes (up to 400 characters, with a counter), an optional Owner and one of eight colors.
  • Drag cards between columns or up and down in a column.
  • Right-click a card for Edit card, Color…, Duplicate Card and Delete card.
  • The status bar counts your cards, for example 12 cards · 4 done.

Boards save themselves about one second after every change.

Connect a document

The connector between the Documents and Kanban tabs links the open document to the board. Save the document first. When you open the board later, TinyEd opens the linked document, too. Click the connector again to Disconnect.

Whiteboards

Sketch diagrams, flows and wireframes on an endless canvas. The whiteboard is based on Excalidraw. Files use the .excalidraw format, so you can also open them on excalidraw.com.

  • Choose File › New Whiteboard (⌥⌘N) or use the New button.
  • The Whiteboards section of the sidebar lists your whiteboards. Click one to open it in the Whiteboard tab.
  • Close it with the ✕ on its tab.
  • The status bar shows how many elements are on the canvas.

Projects

A project keeps a text document, a Kanban board and a whiteboard together. They all have the same name and live in one folder.

Create a project

  1. Choose File › New Project… (⌃⌘N).
  2. Enter a Project name. TinyEd shows where the folder will be created (iCloud Drive › TinyEd).
  3. Click Create. TinyEd creates the folder and opens all three parts.

The new text document already contains a prompt for AI agents, and the board is already connected to the document.

Open, save and close

  • File › Open Project… (⌃⌘O) or a click in the Projects section opens a project.
  • File › Save Project (⌥⌘S) saves all three parts at once.
  • The project capsule in the header shows the project name. Its menu offers Open All Project Tabs, Show in Finder, Copy Agent Prompt, Change Agent Folder… and Close Project.

If a project is open and you open a file from another project, TinyEd opens it in a new window. Your current project stays untouched.

Good to know: There is no hidden project file. A folder is a project when it contains files with the folder’s name. A .txt file you create by hand works instead of the .md file.

Working with AI agents

TinyEd works well next to coding agents such as Claude Code. You plan on the board, the agent picks up tasks and reports back on the same board.

Agent shell

File › Open Agent Shell (⌃⌘T) opens iTerm2 in the agent folder of the project and runs claude -c. Without iTerm2, TinyEd uses Terminal. The first time, you choose the agent folder. Change it later with Change Agent Folder… in the project menu.

The settings live in <Name>.config.json, for example { "terminal": { "app": "iTerm2", "agentPath": "/path/to/agent", "command": "claude -c" } }. You or your agent may add your own keys – TinyEd keeps them.

Good to know: If the config file sets its own start command, TinyEd asks Run start command? before it runs it – and asks again whenever the command changes. If TinyEd may not control iTerm2, allow it under System Settings › Privacy & Security › Automation.

Agents on the Kanban board

A .kan file is plain JSON. Agents may read and change it at any time, even while TinyEd is closed. If the board is open, TinyEd picks up the change within about a second, merges it card by card and highlights changed cards for a few seconds. If you and an agent change the same card, your change wins.

  • Copy Agent Prompt in the project menu copies the rules for agents: take a free card from Backlog, move it through Design, Engineering and Testing to Done, work on one card at a time and keep the notes up to date.
  • The Owner field shows who works on a card. A small capsule on the card shows the name; the tooltip tells you who changed it last and when.
  • Agents must not change cards that belong to someone else.

Fonts, themes and settings

Fonts

Pick a font in Themes › Font: System (Monospace), JetBrains Mono, Fira Code, Cascadia Code, Victor Mono or Monaspace. All fonts come with TinyEd, you don’t need to install anything. Change the size with ⌘+ and ⌘−; ⌘0 returns to Actual Size.

Color profiles

Choose a color profile in Themes › Color Profile: Paper, Sepia, Solarized, Midnight or OMC69. Selected text stays readable in every profile.

Settings

Open TinyEd › Settings… with ⌘,.

  • Display – Appearance Light, Dark or System, plus font and size.
  • AI Assistant – your OpenRouter API key and the default model.
  • Claude Auth – shows your Claude usage limits in the sidebar.

Claude usage limits

  1. Go to Settings › Claude Auth and click Sign in with Claude.
  2. Sign in in your browser and approve access. TinyEd completes the sign-in automatically.
  3. If that fails, copy the address from the browser’s address bar, paste it into TinyEd and click Confirm.

Your 5 h and 7 d limits then appear at the bottom of the sidebar, with the time they reset.

Good to know: This sign-in is unofficial. It uses the public login of Claude Code with read-only access to your profile and usage. The token is stored in your keychain. Sign out removes it.

FAQ

Do I need an API key to use TinyEd?

No. You only need an OpenRouter API key for the AI assistant. Everything else works without a key and without an account.

TinyEd says “Invalid API key”. What now?

Check the key on openrouter.ai/keys and paste it again in Settings › AI Assistant. TinyEd tests the key when you click Save. Make sure your OpenRouter account has credit.

Where does TinyEd save my files?

Wherever you choose in the save dialog. New boards, whiteboards and projects go to the TinyEd folder in iCloud Drive, or to Documents without iCloud Drive. For a project, use Show in Finder in the project menu.

Can I get the original image back after saving?

No. ⌘S bakes the marks into the image for good – that’s why TinyEd asks first. If you want to keep the original, use Save a copy… or ⇧⌘S.

Why can’t I type in my Markdown file?

You are in the formatted view, which is read-only. Press ⇧⌘P to switch back to the source view.

Can an agent and I edit the same board at the same time?

Yes. TinyEd merges changes card by card. If both of you change the same card, your change wins. Cards the agent changed are highlighted for a few seconds.

macOS asks for my keychain password when TinyEd starts.

TinyEd stores your API key and Claude sign-in in the keychain. Enter your password and click Always Allow – then macOS stops asking.

How do I update TinyEd?

TinyEd looks for updates once a day and offers to install them. To check right away, choose TinyEd › Check for Updates….
